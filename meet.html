Create a room or join with a code. Powered by LiveKit when configured on the server.

Setup (one time)
1. Create a free project at cloud.livekit.io
2. Copy WebSocket URL, API Key, API Secret
3. Set server env vars: LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET
4. Restart the server — then Create / Join works here.
